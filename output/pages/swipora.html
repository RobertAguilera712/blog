Swipora

Este proyecto refleja mi capacidad para identificar necesidades de usuario y traducirlas en productos de software orientados a resolver problemas de aprendizaje mediante la ingeniería. Swipora es una aplicación en desarrollo diseñada para optimizar la retención de vocabulario en inglés, sustituyendo los métodos tradicionales de memorización por un sistema inteligente impulsado por algoritmos.

Impacto y Estado Actual del Proyecto

El proyecto se encuentra actualmente en fase activa de desarrollo y validación de mercado. Cuenta con una landing page oficial operativa en swipora.app enfocada en la captación de usuarios tempranos mediante una lista de espera.

Valor Técnico e Ingeniería del Proyecto

El desarrollo técnico de Swipora se centra en la lógica algorítmica, el procesamiento multimedia y el diseño centrado en el usuario:

  • Algoritmo de Repetición Espaciada (SRS): Diseño e implementación de un algoritmo personalizado que analiza las respuestas del usuario y calcula el intervalo óptimo para reintroducir cada palabra justo antes del olvido teórico, maximizando la memoria a largo plazo.
  • Interfaz Gestual de Alto Rendimiento: Desarrollo de mecánicas interactivas de arrastre (swiping) fluidas para la clasificación rápida de tarjetas de aprendizaje, asegurando que el renderizado de la UI se mantenga sin retrasos en la experiencia.
  • Procesamiento de Audio Integrado: Incorporación de sistemas de reproducción de audio nativos y asíncronos para ofrecer retroalimentación de pronunciación precisa en tiempo real sin degradar el rendimiento de la interfaz.

Stack Tecnológico

  • Framework y Lenguaje: Flutter / Dart (Estructura multiplataforma de alto rendimiento).
  • Infraestructura y Landing: Tecnologías de despliegue web para la fase de prelanzamiento y captación de leads.
