Como instalar Python

El día de hoy daremos el primer paso para aprender comenzar a aprender a programar con Python. Vamos a aprender como instalar el interprete de Python y configurar Visual Studio Code para comenzar a escribir y ejecutar código python.

Instalar python

Lo primero es descargar el interprete de python desde https://www.python.org/downloads/.

Una vez descargado ejecutamos el instalador y seguimos sus instrucciones de instalación

Instalar Visual Studio Code

Una vez instalado el interprete de Python vamos a instalar Visual Studio Code, un editor de código de Microsoft que usaremos para escribir nuestros programas en Python. Para ello lo descargamos desde https://code.visualstudio.com/.

Enseguida ejecutamos el instalador y seguimos las instrucciones de instalación

Configurar Visual Studio Code

Después de instalar Visual Studio Code y abrilo por primera vez, vamos a configurarlo. Para esto vamos a la pestaña de extensiones, buscamos python e instalamos las extensiones de python.

Resumen

En este artículo aprendimos como instalar Python y Visual Studio Code, además de configurar este último para así comenzar a escribir nuestros primeros programas en Python. En el siguiente tutorial escribiremos nuestro primer programa en Python y aprenderemos acerca de la entrada y salida de datos.
