Title: Sistema ERP para Gestión de un SPA 
Summary: Desarrollo de una plataforma web integral para la automatización de operaciones, control de clientes y administración de servicios utilizando servicios web REST.

![Interfaz del Sistema My SPA]({static}/images/My SPA.png)

Este proyecto representa una solución integral de software empresarial (ERP) diseñada para digitalizar y centralizar las operaciones diarias de un SPA. El desarrollo se centró en la creación de una arquitectura cliente-servidor eficiente que resuelve problemáticas reales de negocio, tales como la asignación de citas, el control de inventarios, la gestión de personal y el seguimiento de clientes.

## Arquitectura y Valor Técnico

Para garantizar la escalabilidad y el rendimiento del sistema, implementé las siguientes prácticas de ingeniería de software:

* **Arquitectura Orientada a Servicios (SOA):** Construcción de una API RESTful robusta mediante el framework Jersey, logrando un desacoplamiento total entre el backend y la interfaz de usuario.
* **Modelo de Datos Normalizado:** Diseño y optimización de una base de datos relacional en MySQL 8 para asegurar la integridad de la información, el manejo correcto de transacciones y consultas rápidas.
* **Seguridad y Control de Acceso:** Implementación de lógica de negocio orientada a la gestión de roles de usuarios (administradores, empleados, clientes), protegiendo la información sensible del negocio.

## Stack Tecnológico

* **Backend & API:** Java 8 / Jersey Framework (JAX-RS para la creación de endpoints RESTful)
* **Base de Datos:** MySQL 8.0.27 / MySQL Workbench (Modelado, almacenamiento y persistencia de datos)
* **IDE & Herramientas:** NetBeans (Entorno de desarrollo y compilación del backend)

## Habilidades Aplicadas Clave para tu Negocio

* Desarrollo de APIs REST comerciales, seguras y escalables.
* Modelado y administración de bases de datos relacionales con altos estándares de normalización.
* Capacidad para transformar requerimientos operativos complejos en un sistema web funcional y estructurado.
