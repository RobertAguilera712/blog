Title: Cliente de Escritorio para la Gestión de un SPA
Summary: Desarrollo de una aplicación de escritorio corporativa que consume servicios web RESTful, optimizada para la operación diaria y administración de un centro de bienestar.
Tags: Java, Aplicaciones de escritorio, ERP

![Interfaz del Cliente de Escritorio My SPA]({static}/images/My SPA FX.png)

Este proyecto complementa el ecosistema de gestión para un SPA el desarrollo de un cliente de escritorio nativo de alto rendimiento. El software se diseñó específicamente para el personal operativo que requiere una interfaz fluida, rápida y capaz de consumir de manera eficiente la API RESTful centralizada, demostrando mi experiencia en el desarrollo de sistemas distribuidos y arquitectura cliente-servidor.

## Arquitectura y Valor Técnico

El enfoque principal fue garantizar una experiencia de usuario de nivel empresarial y una comunicación asíncrona óptima con el servidor:

* **Consumo de APIs e Interoperabilidad:** Integración avanzada de la capa de red utilizando Jersey Client y Google Gson para la serialización y deserialización de datos JSON en tiempo real.
* **Interfaz de Usuario Avanzada (Material Design):** Implementación de la librería JFoenix sobre JavaFX para construir componentes visuales modernos, dinámicos y altamente profesionales.
* **Experiencia de Usuario Fluida (UX):** Separación de la lógica de diseño mediante FXML y Scene Builder, asegurando que la interfaz mantenga un rendimiento óptimo durante las peticiones al servidor.

## Stack Tecnológico

* **Interfaz Gráfica:** JavaFX / Scene Builder / FXML (Estructura visual modular)
* **Estilos y Componentes:** JFoenix (Componentes basados en Material Design de Google)
* **Comunicación de Red:** Jersey Client (Cliente HTTP para el consumo de endpoints REST)
* **Procesamiento de Datos:** Google Gson (Mapeo y manipulación eficiente de objetos JSON a Java)
* **IDE:** NetBeans (Entorno de desarrollo integrado)
