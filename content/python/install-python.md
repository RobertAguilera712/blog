Summary: En este artículo aprenderás a instalar el intérprete de Python y Visual Studio Code para adentrarte en el mundo de la programación.

El día de hoy daremos el primer paso para comenzar a aprender a
programar con Python. Vamos a aprender cómo instalar el intérprete de Python y
configurar Visual Studio Code para comenzar a escribir y ejecutar código Python.

## Instalar Python

Lo primero es descargar el intérprete de Python desde [https://www.python.org/downloads/](https://www.python.org/downloads/).

![Captura descargar Python]({static}/images/download-Python.png)

Una vez descargado, ejecutamos el instalador y seguimos sus instrucciones de instalación

![Captura instalar Python]({static}/images/install-Python.png)

## Instalar Visual Studio Code

Una vez instalado el intérprete de Python vamos a instalar Visual Studio Code,
un editor de código de Microsoft que usaremos para escribir nuestros programas
en Python. Para ello lo descargamos desde
[https://code.visualstudio.com/](https://code.visualstudio.com/).

![Captura descargar vscode]({static}/images/download-vscode.png)

Enseguida ejecutamos el instalador y seguimos las instrucciones de instalación.

## Configurar Visual Studio Code

Después de instalar Visual Studio Code y abrirlo por primera vez, vamos a
configurarlo. Para esto, vamos a la pestaña de extensiones, buscamos Python e
instalamos las extensiones de Python.

![Captura configurar vscode]({static}/images/configure-vscode.png)

## Resumen 

En este artículo aprendimos cómo instalar Python y Visual Studio Code, además de configurar este último para así comenzar a escribir nuestros primeros programas en Python. En el siguiente tutorial escribiremos nuestro primer programa en Python y aprenderemos acerca de la entrada y salida de datos.
